# Category Reference: <category name, e.g. Plumbing>

> This file is OPTIONAL but recommended. It sits in `website-template/<category>/`
> alongside the reference screenshots. It tells the builder what this genre needs,
> so the agent extracts the right *qualities* from the screenshots instead of guessing.
> It is guidance, NOT a layout to copy.

## Genre essence
One or two sentences on what a customer in this category is feeling and looking for.
Example (plumbing): "Often an urgent, stressful situation. The visitor wants to trust
fast, know help is local and available now, and call with one tap."

## Trust signals this genre relies on
List the credibility cues customers expect. Example (plumbing):
- Licensed / insured / bonded badges
- Years in business, local-and-family-owned
- Emergency / 24-7 availability
- Upfront / flat-rate pricing reassurance
- Before/after photos of real work
- Reviews with names and locations

## Required sections (genre-specific, beyond the rubric defaults)
- Hero with one-tap phone CTA prominently visible
- Services list (drain, leak, water heater, emergency, etc.)
- Service-area statement (which towns/zip codes)
- Trust/credentials strip
- Reviews / testimonials
- Contact + quote-request CTA

## Tone of copy
e.g. "Reassuring, plain-spoken, no jargon, urgency without being pushy."

## Reference screenshots in this folder
Briefly note what each screenshot is a good example OF — so the agent borrows the
right quality. Example:
- `ref-01.png` — clean hero with sticky call button (borrow: clarity, CTA placement)
- `ref-02.png` — strong trust strip (borrow: how credentials are surfaced)
- `ref-03.png` — warm local family-business feel (borrow: tone, photo style)

## Do-not-borrow notes (optional)
Call out anything in the screenshots that should NOT be imitated (a specific brand's
exact colors, a logo, a distinctive illustration style tied to one company).
